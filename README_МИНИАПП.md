# 🤖 Telegram-бот: заметки, напоминания и мини-приложение

Что уже умеет бот:

- 📝 **Заметки** — текст, теги, поиск и голосовые сообщения
- ⏰ **Напоминания** — разовые, с удалением кнопкой
- 🧮 **Мини-приложение** — калькулятор и погода
- 🦜 Эхо-режим и случайное число

Две вкладки мини-приложения:

- **Калькулятор** — скобки, дроби, живой предпросмотр результата
- **Погода** — текущая погода и прогноз на 3 дня по любому городу

Погода берётся из **Open-Meteo** — бесплатно и **без API-ключа** 👍

---

## 🚀 Запуск: одна команда

```bash
cd TelegramBot
pip install -r requirements.txt
python bot.py
```

Бот сам:

1. поднимает локальный сервер мини-приложения (`http://localhost:8080`);
2. открывает **HTTPS-туннель** через `localhost.run`;
3. печатает публичную ссылку и подставляет её в кнопку.

В консоли увидишь примерно это:

```
🌐 Мини-приложение локально: http://localhost:8080
🚇 Поднимаю туннель localhost.run… 10–20 секунд
🔗 Mini App: https://abcd1234.lhr.life
🚀 Бот v2.2 запущен! Для остановки — Ctrl+C
```

Дальше в Telegram: **/start → 🧮 Мини-приложение**.

> ⚠️ Ссылка создаётся заново при каждом запуске бота. Старые сообщения с кнопкой
> будут вести на уже мёртвый адрес — просто нажми **/start**, чтобы получить свежее меню.
> Пока бот запущен, ссылка работает стабильно.

Для мини-приложения регистрация и API-ключи не нужны.
Для голосовых заметок нужен бесплатный ключ Groq — см. раздел «Заметки».

## 🔎 Проверка без запуска бота

```bash
python bot.py --check
```

Поднимет сервер и туннель, проверит публичную ссылку и выйдет.
В конце должно быть:

```
🔎 Проверка публичной ссылки: HTTP 200, ... байт
```

## 🧠 Как это работает (коротко)

1. Telegram открывает мини-приложения **только по `https://`**.
2. Наш сервер живёт на твоём компьютере по `http://localhost:8080`.
3. Туннель `localhost.run` пробрасывает его наружу через SSH и даёт HTTPS-адрес.
4. Бот получает этот адрес и вставляет в кнопку `web_app`.

Запасной вариант — туннель Cloudflare (`cloudflared`). Он остался в коде,
но в некоторых сетях/VPN его домены блокируются, поэтому основным стал `localhost.run`.

Если хочешь **постоянный** адрес — впиши его в `.env`:

```
WEBAPP_URL=https://твой-постоянный-адрес
```

Тогда бот не будет поднимать туннель, а использует этот адрес.

## 📝 Заметки

```
/note Купить молоко
/note #дом Купить молоко
/notes
/find молоко
/find #дом
```

Что умеют заметки:

- **Теги** — пиши `#дом`, `#работа`, `#идея` прямо в тексте.
  По ним тоже работает поиск.
- **Сохранение из сообщения** — ответь на любое сообщение и напиши `/note`.
- **Поиск без учёта регистра** — `молоко`, `МОЛОКО` и `Молоко` найдут одно и то же.
- **Кнопки у заметки** — «⏰ Напомнить» (через час, завтра в 9:00,
  сегодня в 20:00 или своё время) и «🗑 Удалить».
- **Голосовые** — отправь боту голосовое, он распознает речь
  и сразу сохранит её как заметку.

Заметки хранятся в `notes.db` (SQLite) и не пропадают после перезапуска.

### 🎤 Голосовые: нужен ключ Groq

Распознавание речи бесплатное, но нужен API-ключ:

1. Зарегистрируйся на <https://console.groq.com>
2. Создай **API Key**
3. Добавь в `TelegramBot/.env` строку:

```
GROQ_API_KEY=твой_ключ
```

4. Перезапусти бота.

Без ключа всё остальное работает, а голосовые бот вежливо попросит настроить.
Язык распознавания: `STT_LANGUAGE=ru` (по умолчанию русский).

## ⏰ Напоминания в боте

```
/remind 10:00 Купить молоко
/remind 08.11 18:30 Позвонить бабушке
/remind 2026-12-31 23:59 Загадать желание
/reminders
```

Хранятся в `reminders.json`, не пропадают после перезапуска.
Бот проверяет их **раз в 15 секунд** — поэтому он должен быть запущен
(это не облачный сервис, а твой компьютер 😉).

## Если что-то не так

| Проблема | Причина / решение |
|---|---|
| Кнопка «Мини-приложение» показывает подсказку | Туннель не поднялся — смотри консоль бота |
| Старая кнопка в чате не открывается | Бот перезапускался → нажми `/start` и возьми новую |
| Туннель не поднимается | VPN/сеть блокирует SSH (порт 22) — попробуй выключить VPN |
| Страница не грузится локально | Не запущен `python bot.py` или `python webapp_server.py` |
| Погода не загружается | Нет интернета или Open-Meteo временно недоступен |
| Напоминание не пришло | Бот не запущен, или прошло меньше 15 секунд |
| Голосовое не распознаётся | Нет `GROQ_API_KEY` в `.env` или закончился лимит Groq |
| Заметка не находится | Проверь запрос: `/find слово` или `/find #тег` |
| Заметки пропали | Проверь, что файл `notes.db` не удалён и папка доступна для записи |
| Ошибка `aiosqlite` | Выполни `pip install -r requirements.txt` |

├── webapp/
│   ├── index.html         # разметка
│   ├── style.css          # оформление
│   └── app.js             # калькулятор + погода
├── notes.db               # база заметок (появится после запуска)

├── requirements.txt       # aiogram, aiohttp, aiosqlite
└── .env                   # BOT_TOKEN, GROQ_API_KEY и (необязательно) WEBAPP_URL
